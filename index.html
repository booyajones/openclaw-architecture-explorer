Message Lifecycle

How a user message travels through the system and returns as an AI response. Three distinct phases: inbound routing, tool execution, and response delivery.

Inbound — User Message to LLM

👤Userany channel
📨Channelreceive & parse
🧰Routingallow-list + session
🌐GatewayWS server, auth
🤖Agentprompt assembly
🧠LLMinference

Tool Execution Loop

🧪SandboxDocker / exec
