How a user message travels through the system and returns as an AI response. Three distinct phases: inbound routing, tool execution, and response delivery.

02

Architecture Deep Dive

Six layers of the OpenClaw stack. Click any section to expand component details, source paths, and descriptions.

🖥️
1. User-Facing Surfaces
CLI • Web UI • TUI • macOS • iOS • Android
▼
Six entry points for interacting with OpenClaw. The CLI is the primary interface for power users; the Web UI provides a browser dashboard; native apps (macOS, iOS, Android) offer mobile node capabilities. All connect to the Gateway over WebSocket.
CLI — src/cli/ + src/commands/
Web UI — ui/ (Lit + Vite)
TUI — src/tui/
macOS — apps/macos/ (SwiftUI)
iOS — apps/ios/ (Swift)
Android — apps/android/ (Kotlin)
📨
2. Messaging Channels
7 built-in + 21 extension channels
▼
Each channel is a platform-specific adapter that receives messages, normalizes them into OpenClaw's internal format, sends them to the Gateway, and formats responses back for the platform. Built-in channels live in src/; extensions live in extensions/.
WhatsApp — src/web/ (Baileys)
Telegram — src/telegram/ (grammY)
Discord — src/discord/ (Carbon)
Slack — src/slack/ (Bolt)
Signal — src/signal/
iMessage — src/imessage/
LINE — src/line/
21 extensions: Teams, Matrix, IRC, Nostr, Feishu, Google Chat, Mattermost, Nextcloud, Zalo, Tlon, BlueBubbles & more
🌐
3. Gateway Core Engine
~120 files across 5 subsystems
▼
The central nervous system. A single long-lived Node.js process that owns all connections and state. Routes messages, manages sessions, authenticates clients, and orchestrates the agent loop. Everything flows through the Gateway.
Server — Express 5 + WebSocket on :18789
Routing — session key derivation, agent resolution
Sessions — JSONL files per agent session
Auth — shared-secret, Tailscale, trusted-proxy modes
Hooks — event-driven extensibility
src/gateway/
🤖
4. AI Agent Runtime
~250 files — largest subsystem
▼
The Pi-embedded agent runner is the heart of OpenClaw. It assembles system prompts (drawn from skills, memory, and workspace), manages tool execution with policy gating, handles sub-agent spawning, and compacts context windows. The agent loop runs after every LLM response.
Pi Runner — agent loop, system prompts, compact
Tools — Bash, Playwright browser, Canvas
Skills — SKILL.md-driven, 50+ from ClawHub
Sandbox — Docker isolation for tool exec
Sub-Agents — parallel spawning, lifecycle mgmt
Model Catalog — multi-provider routing
src/agents/
⚙️
5. Infrastructure & Storage
Memory, Config, Plugins, Media, Security
▼
Persistence, extensibility, and safety layers. Memory uses SQLite-vec for hybrid semantic+keyword search. The plugin system loads extensions via jiti at runtime. Media pipeline handles transcoding and AI-based analysis. Security audits channels, configs, and skills.
Memory — SQLite-vec, hybrid search, MMR rerank
Config — file loading, session store, profiles
Plugins — jiti runtime, manifest registry
Media — transcoding, format detection, AI analysis
Security — metadata scan, DM policy, ACL
Infra Utils — Tailscale, mDNS, heartbeat, exec approvals
🧠
6. AI Model Providers
22+ provider integrations
▼
OpenClaw supports every major LLM provider. Anthropic Claude is the primary (Pi agent runtime), with OpenAI GPT/o-series, Google Gemini, and Ollama for local models. Additional providers via Bedrock, vLLM, HuggingFace, Together, xAI, DeepSeek, Azure, Groq, Fireworks, Perplexity, Cohere, Replicate, Mistral, and more.

Technology Stack

Languages, frameworks, and tools that power OpenClaw across the full stack.

Language
TypeScript (ESM)
Primary. Strict typing, no any. Node 22+ runtime.
Language
Swift / SwiftUI
macOS & iOS native apps. Observation framework.
Language
Kotlin
Android app. Gradle build system.
Build
tsdown + pnpm
ESM-native bundler. pnpm workspaces monorepo.
Test
Vitest
Unit, e2e, live, extensions configs. 70% coverage.
Lint
Oxlint + Oxfmt
Rust-based linter/formatter. SwiftLint for Swift.
Web
Express 5 + ws
HTTP + WebSocket server on :18789.
Web UI
Lit + Vite
Standards-based web components.
LLM
Pi Agent Runtime
Embedded agent loop from @mariozechner/pi-*.
Browser
Playwright
Headless browser for agent tools.
Storage
SQLite + sqlite-vec
Vector DB for memory. Hybrid semantic+keyword.
Schema
TypeBox + Zod
Tool schemas (TypeBox) + general validation (Zod).
Protocol
ACP
Agent Client Protocol for agent communication.
Deploy
Docker + Fly.io
Containerized deployment, multi-Dockerfile setup.
CLI
Commander
CLI framework with extensive subcommand tree.
