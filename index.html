01

Message Lifecycle

From Chris typing in Slack to a response coming back — the full path through the gateway.

S
Slack Message
Chris sends a message in #general or a DM
→
W
WebSocket Gateway
OpenClaw receives via Bolt socket mode on :18789
→
P
Pi Agent Runtime
Agent loop constructs prompt, resolves skills, builds tool list
→
L
LLM Inference
DeepSeek V4 Flash (primary) processes the prompt with tool schemas
→
T
Tool Execution
Playwright, exec, web_fetch, Salesforce, BigQuery — whatever the task needs
→
R
Response Delivery
LLM output routed back through gateway to Slack channel
