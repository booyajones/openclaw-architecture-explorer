## Where they diverged (adjudicated)

### The cron tag CSS bug

**GPT-5.4 (FATAL FLAW):** "The CSS defines `.cron-tag-fin`, `.cron-tag-per`, `.cron-tag-mix` but the JS uses `'cron-tag-' + c.tag.toLowerCase()` producing `.cron-tag-finexio`, `.cron-tag-personal`, `.cron-tag-mixed`. Every cron row renders without colored tags."

**Claude Opus:** Did not catch this bug.

**Chairman adjudication:** The bug is real and verifiable. `c.tag` = "FINEXIO" → `"cron-tag-" + "finexio"` = `"cron-tag-finexio"` — but the CSS class is `cron-tag-fin`. This applies to all three tags. However, this is a _rendering_ bug, not a _structural_ flaw — it's fixable in under 5 minutes by matching the CSS classes to the rendered values (e.g., `.cron-tag-finexio`, `.cron-tag-personal`, `.cron-tag-mixed`). The fatal flaw designation stands (it's a visible bug on the page) but it's in the SHIP-blocking, not REWORK, category.
